Message keys: `env.*`.
- Providers are free and key-less (Open-Meteo non-commercial CC BY 4.0, sunrise-sunset.org attribution); endpoints overridable by `PHOTOPILOT_WEATHER_ENDPOINT`, `PHOTOPILOT_SUN_ENDPOINT`, `PHOTOPILOT_GEOCODING_ENDPOINT`. Forecast horizon 16 days; beyond it sun data only. Freshness: forecast 3 h, sun 30 d.
- Contracts: times resolved in the provider-verified zone (never the computer's); DST gaps rejected, overlaps resolved so availability only shrinks and labelled; AI windows must stay inside availability, match sun data for their declared light, cite known evidence ids and quote only provider values; Gemini gets label + zone, never coordinates; arrival = user lead time, no travel ETA; Gemini failure keeps facts. Nothing persisted; `ShootingWindow` F09 fields are transient so the v1 session schema is unchanged.
- Design changes (detailed in [f09-environment.md](../Stage2/docs/f09-environment.md#design-changes-original-design--implemented-change--reason--impact)): `assessEnvironment(id, request)` overloads; provider `fetch(place, from, to)`; additive `EnvironmentContext`/`EnvironmentAssessment`/`ShootingWindow` members; `LocationService` lookup/denial; new `PlaceLookupProvider`, `GeocodingAdapter`, `PlaceCandidate`, `EnvironmentRequest`. `EnvironmentTool` implemented (retrieve only) for F10.

Live testing showed a chosen gazetteer place was labelled as entered coordinates (fixed). Pipe CLI commands from a BOM-free file with `cmd /c ... < file` for live runs.
