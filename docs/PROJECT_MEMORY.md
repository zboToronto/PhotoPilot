## Shutter count checker with bundled ExifTool (2026-11-09)

- **Scope.** User-requested real implementation of the Gear Inventory **快门次数检测 / Shutter Count Check** card, which was first added the same day as a UI-only placeholder. - **ExifTool bundle.** Official ExifTool **13.62** Windows 64-bit package. It was downloaded from the exiftool.org download link (SourceForge mirror) and matches the official SHA-256, SHA-1 and MD5 in checksums.txt. It is vendored unmodified in `Stage2/third-party/exiftool/` (511 files, 34.7 MB) with `MANIFEST.sha256`, `NOTICE.md` (licences: Perl terms for ExifTool, Strawberry Perl licences, CC0 launcher) and a `.gitattributes` (`* -text`) so no line-ending conversion breaks the hashes. A `pom.xml` resource entry puts it in `target/classes` and the JAR under `exiftool/`.
- **Decisions.**
  - **Runtime.** PhotoPilot runs `exiftool_files\perl.exe exiftool.pl` in `exiftool_files` rather than the launcher: its `(-k)` name would pause, and killing a launcher could orphan Perl. The process starts lazily with `-stay_open True -@ -` (one per profile context), handles one request at a time with `{readyN}` and `-echo4` markers, drains stdout and stderr on separate threads, and has a 30 s timeout (`PHOTOPILOT_EXIFTOOL_TIMEOUT_SECONDS`). After a timeout or crash it stops the process tree and restarts on the next request; it retries once on a broken pipe. On profile switch or exit it sends `-stay_open False` and kills the process after 3 s. If the JVM dies abruptly, ExifTool exits by itself on stdin EOF (checked).
  - **Locating the bundle.** From class files on disk the bundle is used in place. From a JAR it is extracted once to `%LOCALAPPDATA%\PhotoPilot\exiftool\13.62-<manifest hash>`, SHA-256-verified, and published with an atomic move. Other operating systems report it as unavailable.
  - **Counter selection.** Rules are ported from Sony.pm and Nikon.pm and never treat fields as interchangeable:

- Decisions:
  - **No hardcoded radius.** The system supplies the radius, anti-aliased clipping, 1 px border, shadow and DPI scaling.
  - **No preview build flags.** `java.lang.foreign` (preview in Java 21, final in 22) is called by reflection, so the build needs no `--enable-preview`.

  - **Smoke guard.** The GUI smoke now fails on Windows if the chooser cannot reach the system frame, which protects the launch options.
